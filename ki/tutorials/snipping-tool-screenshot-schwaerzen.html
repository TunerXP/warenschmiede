Windows 11 · Snipping Tool

Screenshot mit dem Snipping Tool schwärzen

So entsteht aus einer Seite mit Zugangsdaten ein bereinigter Screenshot für einen KI-Chat.

Nur eine Bildkopie wird geschwärzt

  • Das Originaldokument bleibt unverändert und sensibel.
  • Weichzeichnen reicht nicht: Stellen deckend schwärzen.
  • Für echtes digitales Schwärzen von PDFs folgt eine eigene Anleitung.
1

Dokument prüfen

Fehlermeldung behalten, Zugangsdaten entfernen.

2

Dokument erfassen

Mit dem Snipping Tool den benötigten Bereich markieren.

3

Schwarzen Stift wählen

Ausreichend dick einstellen.

4

PIN schwärzen

Vollständig deckend übermalen.

5

Benutzernamen schwärzen

Auch Benutzernamen sind Zugangsdaten.

6

Speichern und kontrollieren

Nur die bereinigte Bildkopie speichern.

7

In den Chat einfügen

Dann Fehler und Programm kurz beschreiben.
