# Tool-Übersicht · Webseite 2.0

## Zweck
Diese Version ersetzt die alte Tool-Übersicht mit altem Menü durch eine neue `webseite_2_0`-kompatible Seite.

## Datei
`tools/index.html`

## Änderungen
- alte Header-/Navigationsstruktur entfernt
- zentrale große Menüleiste über `../assets/js/ws-layout.js` eingebunden
- Stylesheet auf `../assets/css/styles.css` umgestellt
- Light-Steel/Warenschmiede-2.0-Optik ergänzt
- Toolkarten aktualisiert und gruppiert
- Suche/Filter bleibt erhalten
- keine Änderungen an den einzelnen Tools selbst

## Einbau
`tools/index.html` nach `webseite_2_0/tools/index.html` kopieren.
