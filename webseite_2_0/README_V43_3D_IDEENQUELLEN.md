# Warenschmiede Webseite 2.0 – V43 3D-Druck Ideenquellen

Diese Version ergänzt die Seite `3d_druck/ideenquellen.html` im Light-Steel-Design.

Wichtig:
- Die Seite nutzt das zentrale Layout-System mit `#ws-header` und `#ws-footer`.
- Es wurde kein statisches Menü in die HTML eingebaut.
- `assets/js/ws-layout.js` wurde im mobilen 3D-Druck-Menü um „Ideenquellen & Portale“ ergänzt.

Kopieren:
- `3d_druck/ideenquellen.html` nach `webseite_2_0/3d_druck/ideenquellen.html`
- optional `assets/js/ws-layout.js` nach `webseite_2_0/assets/js/ws-layout.js`, falls der mobile Menüeintrag noch fehlt
