## Inhalt
- Barcode-Werkstatt Plus um Etiketten-Design ergänzt.
- Designauswahl sitzt links unter Arbeitsmodus, damit die Toolseite nicht unnötig länger wird.
- Druckbogen-Etiketten können jetzt einfache Vorlagen nutzen:
  - Standard weiß
  - Blau modern
  - Orange Warenschmiede
  - Grün Lager / OK
  - Ecken-Rahmen
  - Scan-Me-Badge
  - Industrie kräftig
- Optionaler Titel auf Etiketten:
  - anzeigen ja/nein
  - Titeltext
  - Position oben/unten
  - Farbe
  - Größe
