# Werkstatt-Rechner Metall Plus – v17 Druckblatt modern

Stand: 2026-06-05

## Schwerpunkt
Das Werkzeug-Schnittdatenblatt wurde komplett neu aufgebaut, weil die v16-Ausgabe zwar auf eine Seite passte, aber zu altbacken und teilweise unruhig wirkte.

## Änderungen
- Werkzeugblatt modernisiert.
- Feste Zellstruktur pro Werkzeugblock.
- Kein flexibles Durcheinander durch wechselnde Tabellenbreiten.
- Dritte Zusatzzeile entfernt.
- Kompakter Tool-Bereich links:
  - Toolnummer groß.
  - Drehzahl S direkt darunter/im Block.
  - Vorschub F direkt darunter/im Block.
- Werkzeugname bleibt lesbar.
- Maße kompakt:
  - Länge L.
  - Durchmesser mit Ø-Symbol.
  - Zähnezahl z direkt daneben.
- Zeit, Q/Volumen und Material bleiben draußen.
- A4-Hochkant mit schmalem Rand.
- Schließen-Button im Druckfenster bleibt vorhanden.

## Ziel
Eine moderne, klare A4-Übersicht für die Maschine: wenige wichtige Schnittwerte, immer gleiche Form, gut lesbar und nicht überladen.
