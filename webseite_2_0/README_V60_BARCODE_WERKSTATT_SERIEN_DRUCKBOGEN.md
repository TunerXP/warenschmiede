## Neue Funktionen

### Arbeitsmodi
- Einzelcode
- Gleicher Code mehrfach
- Fortlaufende Serie
- Manuelle Liste

### Serienfelder
- Prefix
- Suffix
- Startnummer
- Anzahl
- Stellen auffüllen
- Schrittweite
- Beschreibung optional

### Druckbogen
- Etiketten pro Reihe
- Kopien pro Code
- Etikettengröße
- Druckbogen-Vorschau
- Druckbogen drucken

### Export
- CSV herunterladen
- Barcode-Inhalt kopieren
- PNG/SVG für Einzelcode
