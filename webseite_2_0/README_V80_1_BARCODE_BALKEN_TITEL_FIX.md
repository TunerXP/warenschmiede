# v80.1 Barcode-Werkstatt Plus · Balken-Titel Fix

## Geändert
- Titelstil `Im Balken schlicht` sitzt jetzt wirklich im oberen oder unteren Balken.
- Titelfarbe wirkt auch bei diesem Stil.
- Wenn der Balken für den Titel nicht eingeschaltet ist, wird er für diese Anzeige automatisch sichtbar gerendert.
- Vorlagen mit Balken-Titel nutzen standardmäßig helle Titelfarbe.
- Zusatz-Zahl unter dem Barcode bleibt standardmäßig aus.
