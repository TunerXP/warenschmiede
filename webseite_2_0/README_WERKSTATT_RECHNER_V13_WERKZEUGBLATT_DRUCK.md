# Warenschmiede Werkstatt-Rechner Metall Plus – v13 Werkzeugblatt-Druck

- Kompakte Werkzeug-Blöcke statt breiter 14-Spalten-Tabelle.
- Pro Werkzeug zwei Zeilen:
  - Zeile 1: T, Werkzeug, Ø, Länge, Beschichtung, Drehzahl, Vorschub, Zeit.
  - Zeile 2: Material, Bearbeitung, vc, f/fz, z, ap/Tiefe, ae, Q.
- Drucklayout nutzt `@page A4 portrait` mit kleinen Rändern.
- Ziel: auch mehrere Werkzeuge übersichtlich auf eine A4-Seite bekommen.
