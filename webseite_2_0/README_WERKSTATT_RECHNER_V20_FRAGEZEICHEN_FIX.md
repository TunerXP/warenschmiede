# Werkstatt-Rechner Metall Plus – v20 Fragezeichen-Fix

## Änderung
- Der feste zentrale Hilfetext aus v19 wurde entfernt.
- Fragezeichen-Hilfen erscheinen wieder als normale Sprechblasen direkt am jeweiligen Fragezeichen.
- Die Sprechblasen werden per JavaScript an den sichtbaren Browserbereich angepasst, damit sie nicht über den Rand laufen.
- Die Sprechblasen liegen mit hoher Ebene über Tabs, Eingaben und Karten.
- Keine Änderung an Rechnerlogik, Projektlogik, JSON oder Druckblatt.
