# V39 – 3D-Druck Fehlerdatenbank

Diese Version ergänzt `3d_druck/fehlerdatenbank.html` im zentralisierten Light-Steel-System.

- zentrales Menü/Footer über `assets/js/ws-layout.js`
- keine statische Menükopie in der HTML
- Fehlerkarten zu Haftung, Stringing, Warping, Elefantenfuß, Unterextrusion, Layer Shift und weiteren Problemen
- Weiterleitungen zu Slicer, Material und 3D-Druck-Service

Kopieren:
`ws_v39_3d_fehlerdatenbank/3d_druck/fehlerdatenbank.html` nach `webseite_2_0/3d_druck/fehlerdatenbank.html`.

Optional `assets/` zusammenführen.
