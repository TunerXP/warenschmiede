# v83.2 Barcode-Werkstatt Plus · Druckform-Fix

## Änderung
- Etikettenform `Eckig` wird im Druck/PDF robuster erzwungen.
- Nicht-Ticket-Formen bekommen keine seitlichen Ticket-Aussparungen/Pseudo-Elemente mehr.
- Zusätzliche Print-Regeln verhindern gerundete Außenkanten bei eckigen Vorlagen.

## Ziel
Die Druckvorschau soll bei Vorlagen wie `Werkstatt Blau/Grau` alle Etiketten gleich eckig darstellen – auch links, mittig und rechts im A4-Raster.
