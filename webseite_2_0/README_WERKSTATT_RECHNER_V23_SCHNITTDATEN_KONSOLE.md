# Werkstatt-Rechner Metall Plus – v23 Schnittdaten-Konsole

Testversion: Die schwarze Schnittdaten-Anzeige wurde zur editierbaren Konsole.

## Neu
- Ø d, vc, S, z, f/fz und F werden direkt in der Konsole eingegeben.
- Die zuletzt geänderten Werte führen die Berechnung.
- Berechnete Felder werden farbig markiert.
- Bohren/Drehen sperren z automatisch.
- Werkzeugkorb und Druckblatt bleiben auf den fertigen Werten.

## Testfokus
- Ø + vc -> S
- Ø + S -> vc
- S + f/fz -> F
- S + F -> f/fz
- Bohren: z gesperrt
- Fräsen: z editierbar
