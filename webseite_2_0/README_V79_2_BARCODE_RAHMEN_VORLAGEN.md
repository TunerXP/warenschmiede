# v79.2 Barcode-Werkstatt Plus · Rahmen-Vorlagen Feinschliff

## Inhalt
- Druckbogen-Rahmen stabiler gemacht, damit die Rundungen/Flächen im Druck sauberer erscheinen.
- Etiketten behalten einen weißen Barcode-Bereich, damit die Lesbarkeit nicht durch Deko gestört wird.
- Neue Vorlagen ergänzt:
  - Balken unten
  - Balken oben & unten
  - Rot Aktion / Hinweis
  - Dunkel Industrie
- Bestehende Vorlagen optisch robuster gemacht.
- Print-Farbkorrektur ergänzt (`print-color-adjust: exact`).

## Einbau
`tools/BarcodeWerkstattPlus.html` nach `webseite_2_0/tools/BarcodeWerkstattPlus.html` kopieren.

Das zentrale Tool-Menü wurde in diesem Stand nicht geändert.
