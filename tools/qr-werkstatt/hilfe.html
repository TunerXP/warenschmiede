Einfach erklärt

Was ist ein QR-Code?

Ein QR-Code ist die maschinenlesbare Darstellung eines Inhalts. Ein Smartphone liest das quadratische Muster und interpretiert beispielsweise einen Link, Text, Kontakt, WLAN-Zugang, Termin oder eine Zahlung.

Der Code ist keine Datenbank, sucht nicht selbst nach Informationen und enthält nur den erzeugten Inhalt beziehungsweise öffnet dessen Ziel.

Wichtig: Ein QR-Code verschlüsselt seinen Inhalt nicht automatisch.

QR-Code oder Inhalt?

QR-Code

Das sichtbare quadratische Muster.

QR-Inhalt

Der tatsächlich gespeicherte Text oder Befehl.

Zielseite oder Datensatz ist das, was nach dem Öffnen erreichbar wird.

Praxisbeispiel

Ein Code kann eine Inventarnummer direkt enthalten oder eine URL zum Inventardatensatz öffnen. Der Code selbst ist aber nicht das Inventarsystem.

Kurze oder lange Inhalte?

Kurze Inhalte ergeben meist ruhigere Codes. Lange URLs und viel Text machen sie dichter; dann ist oft mehr Druckfläche nötig. Kurze, stabile Links können die Scanbarkeit verbessern.

Ein gedruckter Code ändert sich nicht von selbst. Ändert sich eine direkt codierte URL, musst du den QR-Code neu erstellen. Ob ein Link dauerhaft erreichbar bleibt, bestimmt sein Anbieter.
QR-Arten

Allgemein

Link

Öffnet Webseite, Datei, Formular, Download oder Produktseite. Vollständige Adresse verwenden und testscannen.

Text

Liegt direkt im Code und kann ohne Internet angezeigt werden. Viel Text macht ihn dichter.

Standort

Öffnet Adresse oder Kartenlink, etwa für Treffpunkt, Abholung oder Anfahrt. Ziel prüfen.

Bewertung

Öffnet eine Feedbackseite. Eine Bewertung wird nie automatisch ausgelöst; der Nutzer entscheidet.

QR-Arten

Kontakt

vCard

Bietet Name, Firma, Telefon, E-Mail und Webseite als Kontakt zur Übernahme an.

E-Mail

Öffnet eine vorbereitete E-Mail mit Empfänger, Betreff und Text. Sie wird nicht automatisch versendet.

Telefon

Öffnet die Telefonfunktion; der Anruf wird normalerweise noch bestätigt.

WhatsApp

Öffnet Chat oder Nachricht. Nummer mit Ländervorwahl verwenden; Versand erfolgt nicht automatisch.

SMS

Öffnet SMS mit Nummer und optionalem Text. Der Nutzer bestätigt den Versand.

QR-Arten

Zahlung

SEPA

Bereitet Empfänger, IBAN, Betrag und Zweck für eine Überweisung vor. Banking-Apps können sich unterscheiden; Daten immer kontrollieren.

PayPal

Öffnet deinen offiziellen PayPal-Link. Ziel testen und niemals Zugangsdaten codieren.

Zahlungslink

Öffnet den Bezahlvorgang eines Anbieters. Nur vertrauenswürdige eigene Ziele verwenden.

Wero

Das Tool codiert derzeit einen optionalen normalen Zahlungslink, keine darüber hinausgehende Wero-Funktion. Ziel nach dem Scan testen.

Crypto

Codiert Wallet-Adresse und optionale Angaben. Adresse genau prüfen; Transfers sind oft nicht rückgängig. Nie private Schlüssel oder Seed-Phrasen verwenden.

QR-Arten

Alltag & Spezial

WLAN

Enthält SSID, Passwort, Verschlüsselung und Angabe zum versteckten Netz. Das Passwort ist im Inhalt lesbar: bewusst teilen, möglichst Gäste-WLAN nutzen.

Termin

Bietet Titel, Beginn, Ende, Ort und Beschreibung zur Kalenderübernahme an. Zeiten und Zeitzone prüfen.

App-Link

Öffnet App-Store-, Download- oder internen App-Link. Das Ziel muss auf dem Gerät erreichbar sein.

Eingaben

Die Felder ändern sich mit der QR-Art. Ist die automatische Aktualisierung aktiv, folgt die Vorschau deinen Änderungen. Der „Gespeicherte QR-Inhalt“ zeigt genau den codierten Inhalt – kontrolliere dort sensible Daten besonders bewusst.

Optik & Größe

Zur Wahl stehen die Punktformen Rund, Eckig, Punkte und Classy. Das Aussehen darf nie wichtiger als die Scanbarkeit werden.

  • Dunkler Code auf hellem Hintergrund ist am zuverlässigsten.
  • Nicht verzerren, Rand frei halten und keine wichtigen Teile überdecken.
  • Farbige Codes und transparente Hintergründe auf der echten Zielfläche testen.
  • Längere Inhalte brauchen häufig eine größere Ausgabe.
Es gibt keine universelle Mindestgröße: Teste die echte Endgröße, mache einen Testdruck und scanne aus der vorgesehenen Entfernung.

Export & Druck

PNG
Schnell nutzbares Rasterbild für Dokumente und Webseiten; starke Vergrößerung kann unscharf werden.
SVG
Skalierbare Vektorgrafik für Druck, Schilder und Weiterbearbeitung.
Inhalt kopieren
Kopiert nicht das Bild, sondern den tatsächlich codierten Inhalt.
Drucken
Browser-Druckdialog und Vorschau nutzen, unnötige Skalierung vermeiden und Ausdruck erneut scannen.

Projekt laden
QR-Art, Eingaben und Einstellungen aus einer QR-Projektdatei wiederherstellen.
Version speichern
Snapshot im lokalen Projektverlauf und in der Projektdatei sichern.

Wird im Browser gespeichert und ermöglicht späteres Weiterarbeiten.

Setzt nach Bestätigung lokale QR-Daten und Versionen unwiderruflich zurück.
JSON ist eine Datei zum Weiterbearbeiten, keine fertige Grafik. PNG und SVG sind die Bildausgaben.

Scanbarkeit & Kontrast

Halte starken Kontrast, einen hellen ruhigen Hintergrund und den freien Rand um den Code ein. Beschneide oder verzerre ihn nicht. Kleine, dichte Codes brauchen besondere Sorgfalt.

  1. In der vorgesehenen Endgröße ausgeben.
  2. Testdruck auf dem echten Material erstellen.
  3. Mit mehreren Smartphones oder Scannern aus der geplanten Entfernung testen.

Datenschutz & sensible Daten

Die QR-Erzeugung erfolgt im aktuellen Tool lokal im Browser; heruntergeladene Projektdateien liegen anschließend bei dir. QR-Inhalte sind weder automatisch geheim noch verschlüsselt: Jeder mit Zugriff auf den Code kann sie scannen.

  • WLAN-Passwörter, Kontakt- und Standortdaten nur bewusst teilen.
  • Keine Passwörter, privaten Schlüssel oder Seed-Phrasen öffentlich codieren.
  • Zahlungsdaten sorgfältig prüfen.
  • Ziel-Links können später andere Inhalte zeigen, wenn die Zielseite geändert wird.
  • Fremde QR-Codes grundsätzlich mit Vorsicht öffnen.

Testen & Fehler lösen

QR-Code scannt nicht

Größer drucken, Kontrast erhöhen, ruhigen hellen Hintergrund nutzen, nicht beschneiden, Inhalt verkürzen und anderen Scanner testen.

Falscher Inhalt

Gespeicherten QR-Inhalt, vollständige URL, Ländervorwahl sowie WLAN-Name und Passwort prüfen. Wurde versehentlich eine alte Grafik genutzt?

PNG wirkt unscharf

Größere PNG-Ausgabe oder für skalierbaren Druck SVG verwenden.

WLAN verbindet nicht

SSID, Passwort, Verschlüsselung, verstecktes Netz, Sonderzeichen und Gerätekompatibilität prüfen.

Projekt lädt nicht

Ist es wirklich eine unveränderte QR-Projekt-JSON und nicht PNG oder SVG?
