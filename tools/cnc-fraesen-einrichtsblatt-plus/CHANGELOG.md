# Changelog – Warenschmiede CNC Fräsen-Einrichtsblatt Plus

## v1.0.35.0

- Toolname geändert auf „Warenschmiede CNC Fräsen-Einrichtsblatt Plus“.
- Fokus klar auf Fräsen gelegt.
- Drehmaschine als aktiver Maschinentyp wieder entfernt.
- Achsauswahl startet wieder bei 3 Achsen.
- Werkzeugtypen auf Fräs-/Bohr-/Messwerkzeuge bereinigt.
- Werkzeugberechnung wieder klar auf Fräsen fokussiert: `vf = n · z · fz`.
- README und Demo-Daten auf Fräsen-Fokus angepasst.

## Hinweis

Drehmaschinen sollen später als eigenes Modul oder eigenes Tool geplant werden, nicht in dieser Fräsen-Hauptversion.
